Xian的笔记

      关于这个博客

      这里用来存放技术笔记、项目复盘、求职记录和一些兴趣资料。内容按分类、归档和搜索进入，不需要记住文章放在哪个文件夹。

      它怎么发布

      每篇文章都是仓库中的一个 Markdown 文件。补一条文章索引后，通过 Git 推送即可由 GitHub Pages 自动发布。

      详细步骤见 发布文章流程。

      公开内容边界

      只发布可以公开的资料，不放客户数据、内部系统地址、账号密码、密钥和个人敏感信息。后续如果接入 AI 对话，密钥和服务端逻辑也会放在独立后端，而不是这个静态博客里。
