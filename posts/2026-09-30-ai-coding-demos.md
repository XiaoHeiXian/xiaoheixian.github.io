## AI 辅助前端开发：本地记账小工具

通过 Copilot Chat 实现纯 HTML 轻量化工具开发，体验 AI 辅助全流程开发，熟悉需求拆解、代码生成、迭代优化流程，所有数据本地存储、无需联网。

操作步骤如下：

（1）创建 aitools 文件夹（如：E:\ai\aitools）

（2）在 VS Code 打开 aitools 文件夹（作为项目的目录）

（3）打开 Copilot Chat，输入以下需求：

    帮我做一个纯 HTML 的本地日常开销记账小工具，能输入消费金额、分类、日期，自动统计月度总支出，界面用清爽的浅蓝风格，所有数据存在本地浏览器里不用联网。

（4）发送

（5）等待代码生成，在生成过程中需要手动“允许”代码审核

（6）完成后，保留文件，会在当前项目生成一个.html 文件（如：index.html）。

（7）打开文件

进入 aitools 文件夹，直接打开 index.html（每次生成页面效果不会相同），结果如图 1 所示（表格包含日期、分类、金额、操作，带有删除按钮，底部有提示“数据保存在本地浏览器，关闭页面后可在同一浏览器继续查看”）。

## 数据可视化实践：农作物数据分析

基于 CSV 原始数据，完成数据清洗、分类统计、可视化图表生成、自动生成分析报告，掌握 AI 辅助数据处理、代码调试、报告输出的完整流程，为后续文本数据预处理奠定实操基础。

操作步骤如下：

（1）将文件“2024 年种植业数据.csv”复制到指定文件夹（如：E:\user\data）

（2）在控制台安装 pandas

    conda activate ai_env
    conda install pandas

（3）打开 Copilot Chat，输入以下需求：

    本地 e:\usr\data 有文件：2024 年种植业数据.csv，现需要做如下操作：
    1. 数据清洗
    （1）删除数值为 0 的数据
    （2）删除品类中包含人均的品类
    （3）将指标为产量的数值单位中的万吨统一转换为吨
    （4）将指标为播种面积/种植面积统一转换为转换为种植面积
    （5）将指标为种植的数值单位由千公顷转换为亩
    2. 农作物结构分析
    （1）粮食作物通常包括：水稻、小麦、玉米、大豆、薯类、谷物等
    （2）经济作物通常包括：油料、棉花、糖料、蔬菜、水果、茶叶、烟叶、药材等
    （3）其他作物：饲料、绿肥等
    用饼状图呈现出各类作物和产量比例和种植面积比例
    3. 分析报告
    帮我制作一份纯 HTML 的分析报告，并对报告进行解读
    4. 生成 python 源码文件

（4）发送

（5）等待代码生成，在生成过程中需要手动“允许”代码审核

（6）完成后，保留文件，会在当前项目生成一个.html 文件（如：analysis_report.html）和源代码文件（如：analize_crops.py）。同时在 E:\user\data 文件夹下生成“种植业分析报告.html”。

（7）打开文件

进入 aitools 文件夹，直接打开 analysis_report.html，结果如图 2 所示（页面顶部为分析报告标题，中间包含总产量、总种植面积的统计卡片，紧接着是产量结构的饼状图与表格，下方包含详细的分析报告解读文本）。

💡 **速记**

**【案例1：本地记账小工具】**
*   **目标**：通过 Copilot Chat 生成纯 HTML 工具，实现记账、分类、日期、自动统计月度支出、本地存储、无需联网。
*   **关键步骤**：建文件夹 -> VS Code 打开 -> 发送 Prompt -> 允许代码审核 -> 生成 `index.html` -> 浏览器打开。
*   **AI 提示词技巧**：明确功能（纯HTML）、输入字段（金额/分类/日期）、核心逻辑（自动统计月度支出）、样式（浅蓝清爽）、数据存储（本地浏览器无需联网）。

**【案例2：农作物数据分析】**
*   **目标**：基于 CSV 完成数据清洗、结构分析（饼状图）、生成 HTML 报告。
*   **准备工作**：复制 CSV 到指定目录，安装 pandas（`conda activate ai_env` + `conda install pandas`）。
*   **AI 提示词技巧（高频考点）**：
    1. 明确数据源路径。
    2. 数据清洗规则：删0、删包含“人均”的品类、单位转换（万吨->吨，千公顷->亩）。
    3. 分析需求：按粮食/经济/其他分类，用饼状图展示产量与面积比例。
    4. 输出要求：纯HTML报告并解读，同时输出Python源码文件。
*   **生成结果**：`analysis_report.html` 和 `analize_crops.py`，原始数据目录生成分析报告。
*   **核心体验**：AI 辅助完成需求拆解、代码生成、迭代优化，人负责审核与验证。
