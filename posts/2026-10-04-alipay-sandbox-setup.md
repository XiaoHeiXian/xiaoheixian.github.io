很多项目都需要有支付功能，但是对接第三方支付又需要企业资质，作为个人开发者，达不到这个条件，支付宝沙箱可以解决这一痛点。通过使用支付宝沙箱，我们就能够在项目中模拟真正的支付，让我们的项目锦上添花。使用支付宝沙箱无需企业资质，只需要一个支付宝账号。

## 1、什么是支付宝沙箱

支付宝沙箱（Alipay Sandbox）是支付宝为开发者提供的一个模拟真实支付宝环境的测试平台。开发者可以在沙箱环境中进行应用程序的开发和测试，无需使用真实的支付宝账户进行交易。

## 5、设置内网穿透

在支付宝沙箱支付中，支付宝服务器会在支付完成后发送回调通知（支付结果）到开发者的后端服务。这些回调通知需要开发者的服务有一个公网可访问的 URL。如果开发者的后端服务运行在本地或公司内网，支付宝的服务器无法直接访问，因此需要通过内网穿透工具暴露本地服务到公网。

内网穿透（NAT 穿透）是指在没有公网 IP 的情况下，让处于不同局域网的设备能够直接通信，或将局域网内的服务暴露给互联网访问的技术。其核心目的是解决私有地址（如 192.168.x.x、10.x.x.x 等）无法在公网路由的问题，通过穿透 NAT（网络地址转换）设备，实现内外网互联。

### 常见应用场景

- 开发测试：临时将本地开发的 Web 服务（如 Django、Node.js）暴露给外网协作或演示。

- 远程访问：从外部网络访问家庭或企业内网的服务器、数据库等资源。

- P2P 通信：实现不同局域网设备间的直接数据传输（如文件共享、视频通话）。

内网穿透的第三方平台 NATAPP：https://natapp.cn/

### （1）创建隧道

官网右上角注册，先注册账户，登录后，进行实名认证，购买一个免费隧道：

名称：沙箱支付

隧道协议：Web

Web: 普通型http(s)隧道穿透,用于搭建网站,微信开发等穿透到本地web服务.

TCP: 端口转发,应用于SSH,数据库,远程桌面,GAME等基于TCP连接的一切应用任您想象~(禁止http(s))

UDP: 端口转发,应用于游戏,远程开机等基于UDP协议的一切应用

选定后不可更改

域名/远程端口：系统随机分配

本地端口：9000（与 Gateway 端口相同）

价格：0 元

## 6、流程图文字推演

### 支付宝沙箱支付与回调流程

用户在电商系统下单 --> 调用 alipay.trade.page.pay 生成跳转链接 --> 用户浏览器跳转至支付宝沙箱页面 --> 用户使用沙箱买家账号登录并支付 --> 支付宝服务器处理支付 --> 支付宝服务器发送异步回调通知 --> 回调请求通过内网穿透工具(NATAPP)转发 --> 本地开发环境接收回调并处理业务逻辑 --> 返回处理结果给支付宝服务器

### 内网穿透配置与启动流程

访问 NATAPP 官网注册并实名认证 --> 购买免费 Web 隧道（配置本地端口 9000） --> 记录系统分配的 authtoken 和公网域名 --> 下载对应系统的客户端并解压 --> 在命令行执行 natapp.exe -authtoken=你的authtoken --> 启动成功，公网域名与本地端口建立映射 --> 支付宝回调可通过公网域名访问本地服务

💡 **速记**

【核心考点】

支付宝沙箱是个人开发者突破企业资质限制，进行支付功能开发与测试的官方模拟平台。

内网穿透的核心目的是解决公网无法直接访问本地/内网私有地址的问题，确保支付回调通知能到达本地开发环境。

【高频逻辑链】

配置沙箱应用 --> 获取 APPID 与 PID --> 配置公钥模式 --> 查阅 API 文档（使用 alipay.trade.page.pay） --> 配置账户充值 --> 配置内网穿透（NATAPP） --> 启动客户端映射本地端口 --> 测试支付与回调。

【关键避坑】

内网穿透的本地端口必须与本地实际提供服务的端口（如 Gateway 端口 9000）保持一致。

执行 natapp.exe 时不能直接双击，必须在 cmd 命令行中指定 authtoken 执行，且启动后命令窗口不能关闭。
