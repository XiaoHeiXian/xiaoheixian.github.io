## 1.3.1 概述

### 1、Deepseek-harness 优势

#### 1）一切皆插件（Cordis 内核）—— 最大卖点

（1）传统 Agent (LangChain、AutoGPT)：模型、工具循环、UI、存储写死代码里，改能力要改源码。

（2）DSH：模型适配器、工具、沙箱、会话存储、Agent 循环、Web 界面全部是插件。不用改源码，配置文件即可插拔替换。如果不想用 shell 工具，直接卸载 shell 插件；想换 UI，装另一个 UI 插件即可。Cordis 内核只管理插件加载、事件、依赖，不做业务逻辑。

#### 2）完整可追溯执行日志（Append-Only 会话日志）

（1）每一步：系统提示、思考、工具调用、返回结果、子 Agent 调度全部追加写入日志，不会被上下文压缩删除。

（2）排错神器：Agent 做错，能回看模型当时完整看到了什么。

#### 3）完整编码 Agent 原生运行循环

（1）不是简单 ReAct 循环，官方定义闭环：意图 -> 契约 -> 上下文 -> 执行 -> 证据 -> 修复 -> 可发布产物。

（2）专门面向写代码、改项目、调试 bug，不是普通聊天。

（3）自带：本地文件读写、shell 执行、diff 编辑、文件查找、代码修改，工具调用框架层封装好了，不用自己写 ReAct 代码。

#### 4）安全沙箱机制

文件、shell 执行有权限控制，工作目录隔离，防止乱删系统文件；插件支持热插拔，有依赖契约校验。

### 2、插件分类

插件分为两大类：官方内置工具插件 + 社区生态插件。

#### 1）官方内置基础工具插件（开箱自带）

    fs-tool：文件读写、创建、diff 修改、查找文件。说明：读写工作区项目源码，核心编码工具。
    shell-tool：执行 shell 命令、运行脚本。说明：编译、npm install、运行测试，高危，严格限定工作目录。
    git-tool：git status/commit/diff。说明：项目版本操作。
    skill-loader：技能加载系统。说明：加载.skill.md 技能包，扩展任务能力。
    sandbox：沙箱隔离插件。说明：限制文件 /shell 访问边界。
    model-providers：模型适配器插件。说明：对接 DeepSeek、Ollama、OpenAI 兼容接口。

内置插件就是 Agent 干活的基础：读代码、改代码、跑命令、git 操作。

#### 2）热门社区第三方插件（Oh-My-DSH 生态）

安装第三方插件命令：

    dsh plugin --profile web add github:xxx/xxx#main

安装插件市场命令：

    dsh plugin --profile web add dshmarket

##### 1) UI 增强类

    dsh-better-sidebar：VSCode 风格侧边栏，文件树、内嵌终端、git 面板、diff 预览，弥补原生 web 光秃秃界面。
    dsh-tui：终端全屏 TUI 界面，不用浏览器，命令行操作 Agent。
    dsh-genui：AI 直接渲染 Mermaid 图表、表格、diff 面板，可视化输出。
    dsh-usage-stats：多供应商用量看板：按供应商/模型统计 Token 与日期下钻，统一展示账户余额。

##### 2) 视觉读图能力（DSH 本体是文本框架，没有视觉）

    ModLens：图片 OCR 解析插件，粘贴截图，调用外部视觉模型转为文本给主模型；支持对接本地 Ollama 视觉模型。（注意，有些模型需要配置视觉引擎，将这句话“帮我配置一个免费的视觉引擎”，harness 就会帮你完成配置，配置过程中需要你配置一些操作）
    dsh-vision-proxy：自动探测本机 Ollama，用本地多模态模型做看图，不上传外网图片。

##### 3) 开发调试增强

    dsh-context：上下文洞察面板：一眼看清模型上下文窗口的组成与变化——构成对照窗口大小、按请求历史趋势、压缩/注入事件、消息级 token 统计。
    dsh-context-doctor：统计每一个插件 / 工具 schema 占用多少 token，检测上下文膨胀、冗余，做 Agent 调优，非常实用。
    dsh-at-file：聊天框 @文件名快速引用本地文件，不用复制粘贴路径。
    dsh-open-in-vscode：DSH 工作区一键在 VSCode 打开项目文件夹。

##### 4) 自动化 & 扩展能力

    dsh-automation：定时任务，定时跑 Agent 任务，后台会话调度。
    dsh-reverse-skill：85 个安全审计 / 逆向工程技能包，安全研究向。
    engram-relay：超长记忆插件，扩展上下文记忆，类似长期记忆向量库替代品。

## 前端“为你推荐”模块设计

在电商商城的 AI 自然语言智能搜索场景中，前端页面需要进行如下改造：

1. **搜索框模式切换**：增加一个切换开关，允许用户在【传统 ES 关键词搜索】和【AI 自然语言智能搜索】之间进行选择。
2. **“为你推荐”模块**：当用户使用 AI 自然语言智能搜索时，系统除了通过传统 ES 返回搜索结果外，前端会向 Java 微服务请求 `/v1/search/recommend` 接口。该接口通过 OpenFeign 调用 Python AI 服务，返回大模型结合向量检索生成的 JSON 数据。
3. **结果展示**：前端解析该 JSON 数据，在商品列表下方动态渲染出一个名为“为你推荐”的专属栏目。该栏目不仅展示推荐的商品列表（包含图片、名称、价格），还会展示 AI 生成的“总结导语”（summary）和“推荐理由”（reason），以导购对话的形式呈现给用户，提升购物体验与转化率。

## 流程图文字推演

### DSH 插件化 Agent 运行循环

用户输入意图 --> Cordis 内核调度
--> 读取配置加载对应的模型适配器插件 (model-providers)
--> 加载上下文，启动 Agent 循环
--> 模型思考并决策调用工具 (如 fs-tool, shell-tool)
--> 执行环境 (sandbox) 进行权限校验隔离
--> 执行工具并将结果追加至 Append-Only 日志
--> 根据执行证据 (代码、diff、日志) 进行自我修复或继续
--> 最终输出可发布产物 (如生成的小程序代码)

## 💡 **速记**

【核心考点】

DSH 的核心竞争力在于“一切皆插件”的架构，使用 Cordis 内核，将所有能力（模型、工具、UI）解耦，实现真正的开箱即用与按需组装。

原生 Agent 循环针对编码场景专门优化：意图 -> 契约 -> 上下文 -> 执行 -> 证据 -> 修复 -> 产物，这比普通的对话 ReAct 循环更适合复杂项目开发。

安全性与可观测性：提供 Append-Only 的执行日志，确保每一步思考与操作可追溯；内置沙箱隔离，防止执行高危命令破坏系统。

【高频逻辑链】

需求输入 --> 内核调用模型 --> 规划任务 --> 调用内置工具（文件/Shell/Git） --> 记录详细日志 --> 校验与修复 --> 产出结果。

【关键避坑】

使用第三方社区插件时，要注意安装命令的环境配置，需指定 profile (如 web) 以确保插件在正确的上下文中生效。

执行 shell 等高风险工具时，务必确保工作目录已被安全沙箱（sandbox 插件）隔离，防止 Agent 幻觉导致误删系统文件。
