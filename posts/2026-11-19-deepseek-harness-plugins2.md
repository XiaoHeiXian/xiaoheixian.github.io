## 【案例一】生成个人简历小程序

操作步骤：
（1）创建工作区：创建 E:\user\deeseek\my 目录
（2）将个人简历 word 文档存到 E:\user\deeseek\my 下
（3）将 E:\user\deeseek\my 设置为 harness 工作区
（4）输入提示词：

    根据简历模板，帮我生成一份 Apple 科技风格的个人简历微信小程序，要求：按标题分成不同的栏目和页面。

生成结果展示：系统自动生成了包含首页、核心竞争力、技术栈等多个 UI 页面的小程序代码，并支持在界面中快速浏览。

## 【案例三】生成汽车营销系统

输入提示词：

    请帮我完整开发一套【汽车营销系统】，严格按照下面架构、技术栈、模块、数据库要求输出，输出完整可运行代码，给出项目结构、关键代码、建表 SQL、模拟 Mock 测试数据、运行说明。

    ## 整体系统架构
    系统分为两大模块：
    1. 营销前端面向普通客户：SpringBoot + Thymeleaf 服务端渲染，非前后端分离
    2. 管理后台面向管理员：SpringBoot 后端接口 + Vue3+Axios 完全前后端分离架构
    两套模块共用同一套数据库。

    ## 技术栈约束
    ### 公共后端
    - SpringBoot 3.2.x, MyBatis, Lombok
    - 数据库：MySQL，提供完整建表 SQL，同时提供 Mock 模拟数据脚本，大量填充模拟业务测试数据
    - 统一返回 Result 封装类，全局异常处理，跨域配置（给 Vue 后台使用）

    ### 营销前端（客户访问端）
    - 技术：SpringBoot + Thymeleaf 模板引擎
    - 页面：Thymeleaf + Bootstrap 简易页面，不需要 Vue
    - 功能模块：
    1. 首页：汽车广告轮播、热门车型展示、优惠活动展示
    2. 车型列表页：筛选品牌、价格区间、车型分类，汽车详情跳转
    3. 汽车详情页：车辆图片、参数、报价、配置、预约试驾按钮
    4. 预约试驾表单：用户提交预约信息，提交保存到数据库
    5. 活动公告页面：展示营销活动
    6. 用户简单留言咨询功能

    ### 管理后台（管理员）【前后端分离】
    - 后端：SpringBoot，只输出 RESTful JSON 接口，不做页面渲染
    - 前端：Vue3 + Axios，使用简单 Element Plus 组件库，独立前端项目
    - 后台功能模块：
    1. 管理员登录、token 会话鉴权
    2. 汽车车型管理：新增、编辑、删除、分页查询汽车信息（品牌、型号、价格、图片、排量、颜色、库存）
    3. 品牌管理：汽车品牌增删改查
    4. 营销活动管理：活动发布、上下架
    5. 预约试驾管理：查看客户预约记录、状态修改（待处理/已联系/已完成）
    6. 用户留言咨询管理
    7. 简单数据统计：车型数量、预约数量看板

    ## 数据库&Mock 模拟数据要求
    1. 输出完整 MySQL 建表语句，表至少包含：管理员表、汽车品牌表、汽车车型表、营销活动表、预约试驾表、留言咨询表
    2. Vue3 管理后台关键页面、axios 请求示例
    3. application.yml 配置文件
    4. 请严格按照以下要求生成图片：
    （1）请在 `car-backend/src/main/resources/static/images/` 目录放置真实图片
    （2）禁止使用图片占位符，图片必须是真实车辆图片，不允许用其它品牌或图片替换
    （3）可以到汽车之家去下载车辆图片，如果汽车之家没有同车型图片，到其它网站下载
    （4）汽车图片缩略图必须是图片全貌，不允许只显示图片一部分
    5. 完整启动步骤，说明如何运行营销前端、如何启动 Vue 管理后台，注意事项。
    要求代码尽量完整可直接运行，注释清晰，不要只写伪代码。

## 前端“为你推荐”模块设计

在电商商城的 AI 自然语言智能搜索场景中，前端页面需要进行如下改造：

1. **搜索框模式切换**：增加一个切换开关，允许用户在【传统 ES 关键词搜索】和【AI 自然语言智能搜索】之间进行选择。
2. **“为你推荐”模块**：当用户使用 AI 自然语言智能搜索时，系统除了通过传统 ES 返回搜索结果外，前端会向 Java 微服务请求 `/v1/search/recommend` 接口。该接口通过 OpenFeign 调用 Python AI 服务，返回大模型结合向量检索生成的 JSON 数据。
3. **结果展示**：前端解析该 JSON 数据，在商品列表下方动态渲染出一个名为“为你推荐”的专属栏目。该栏目不仅展示推荐的商品列表（包含图片、名称、价格），还会展示 AI 生成的“总结导语”（summary）和“推荐理由”（reason），以导购对话的形式呈现给用户，提升购物体验与转化率。

## 流程图文字推演

### DeepSeek Harness 自动化编码与建站流程

用户在 DSH 工作区输入长文本 Prompt（包含详细的技术栈、架构约束和业务需求）
--> Cordis 内核调度加载对应的模型
--> Agent 解析意图并规划任务
--> 调用 fs-tool 创建项目目录结构
--> 调用 shell-tool 初始化 Maven/Vue 项目
--> 模型生成代码内容，通过 fs-tool 写入文件
--> 自动化下载真实车辆图片存入 static/images 目录
--> 检查并生成数据库建表 SQL 和 Mock 数据
--> 输出完整可运行的项目及启动说明

## 💡 **速记**

【核心考点】

DeepSeek Harness 展现了强大的零代码/低代码生成能力，只需提供详细且结构化的 Prompt（包含架构、技术栈、功能清单、数据库要求等），即可驱动 Agent 自动生成包含前后端的完整项目。

在生成前端 UI 时，Agent 具备多模态能力，能够根据提示词（如“Apple 科技风格”）直接生成高度定制化、美观的页面。

生成复杂系统时，清晰的“约束条件”至关重要，例如明确前后端技术栈差异（Thymeleaf vs Vue3）、Mock 数据要求、甚至图片必须是真实全貌的硬性要求，这能有效避免 AI 幻觉和敷衍。

【高频逻辑链】

配置工作区 --> 编写结构化 Prompt --> Agent 规划与工具调用 --> 生成源码、SQL、目录结构 --> 执行代码构建与测试 --> 输出可发布产物。

【关键避坑】

虽然 DSH 能生成完整代码，但对于业务逻辑极其复杂的系统，仍需人工审查核心代码逻辑，特别是数据库索引设计、接口安全性（如鉴权拦截）等关键环节。

对于依赖外部资源（如真实车辆图片）的生成任务，由于网络环境或版权限制，Agent 可能无法下载真实的图片资源，导致项目运行时图片无法显示，需要人工干预替换。
